# **Codigo em Linha e Bloco de Codigo**:

Use uma crase para destacar um comando ou treço curto no meio de uma frase.

O comando `git status` mostra o estado atual repositorio.

O comando `git add .` adiciona os arquivos notificados a staging area.

O comando `git commit -m` `Texto com a descrição do que foi feito` registra as alterações com uma mensagem.

O comando `git push origin main` sobe as alterações para a nuvem.

Ctrl + J-Abre o Terminal
```
git status 
git add .
git commit -m "Texto com a descrição do que foi feito"
git push origin main
```
